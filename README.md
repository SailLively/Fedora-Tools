# Fedora-Tools
Small Fedora/KDE helper scripts.(since my system breaks like once a month)

- fix-kde — restart the Plasma shell when the desktop starts acting weird.
- fix-network — toggle networking and optionally force a NetworkManager restart.
- fix-updates — rebuild the RPM database, clean dnf cache, upgrade packages, and repair Flatpaks.
- downscale — pick a display and switch it to a clean lower resolution in KDE.)(mainly gaming use)


Drop these in ~/.local/bin and run them directly.
